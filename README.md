# Metra_Project-Public

Built site and published data for **https://metra.jesse-anderson.net**, an independent
analysis of Chicago-area commuter rail reliability.

> **This site is not sponsored by, affiliated with, or operated by Metra.**
> Data is obtained from Metra (GTFS and GTFS-Realtime) and redistributed from our own
> host. It is provided as-is, with no claim of accuracy, completeness or timeliness.
> Every dataset is stamped with its last-updated time.

This repository holds **built artifacts only**: the compiled site, small data files and
a manifest. The pipeline that produces them lives in a private repository. Each publish
force-pushes this repo, so history is intentionally not preserved.

Licensing for code and derived data will be stated here before launch.
